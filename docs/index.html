About This Project

This educational project uses the Longest Common Subsequence (LCS) algorithm and dynamic programming to compare two DNA sequences. It demonstrates how sequence comparison can be explored through computer science.

01

Sequence Validation

Accepts DNA bases A, T, G and C.

02

Dynamic Programming

Builds a table to find the LCS efficiently.

03

Clear Results

Displays the common subsequence, length and similarity.

Educational demonstration only. This tool is not intended for medical diagnosis or clinical decision-making.
